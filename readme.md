# NocturnalOS

NT-подобная операционная система, написанная с нуля.
UEFI-only, x86_64, SMP — не опция, а требование.

---

## О проекте

NocturnalOS — операционная система, написанная с нуля
с использованием идей оригинальной NT-архитектуры,
но в собственном понимании.

Это **не** попытка сделать «серьёзную» ОС с планом и целью.
Это проект ради забавы — чтобы скоротать время и разобраться,
как оно всё устроено под капотом.

Разрабатывается одним человеком. Код доступен на GitHub.
ОС умеет загружаться на реальном железе, работа в этом
направлении ведётся.

**Требования к железу:**
- x86_64, UEFI (BIOS не поддерживается)
- SMP — обязательно
- ARM64 — в планах

## Архитектура

### Стек сборки

- **Компилятор:** Clang, `-target x86_64-w64-windows-gnu`
- **Сборка:** CMake + Ninja
- **Флаги:** freestanding, `-mgeneral-regs-only`,
  `-fno-stack-protector`, `-mno-red-zone`
- **Ядро:** PE, `--subsystem,native`, image-base 0x400000

---

## Соглашения по коду

- **Стиль:** NT-подобный (`Ki`, `Ke`, `Ps`, `Mm`, `Ob`, `Io`, `Hal`)
- **Типы:** `UINT32`, `ULONG64`, `HANDLE`, `NTSTATUS`, `VOID`
- **Комментарии:** по-русски, коротко, по делу

**Префиксы:**
- `Ki*` — kernel init / internal
- `Ke*` — kernel executive
- `Halp*` — HAL private
- `Mi*` — memory internal
- `Obp*` — object private
